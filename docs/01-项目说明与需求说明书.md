## 一、项目概述

### 1.1 项目名称

**InsightForge Personal Edition**（以下简称“InsightForge 个人版”）

### 1.2 项目定位

InsightForge 个人版是一套**完全自包含、可本地运行的市场验证工具箱**。它帮助个人创业者、产品经理和研究者，在**无需任何云服务注册**的前提下，快速验证一个产品想法是否存在真实的市场需求。

> **核心理念**：从模糊想法到有数据支撑的市场报告，只需 5 分钟。

### 1.3 项目愿景

成为每一位创新者的“**私人市场验证助理**”——让每一个好想法都能在被投入大量资源之前，先得到数据的检验。

### 1.4 与同类项目的区别

| 项目 | 定位 | 与本项目的区别 |
|------|------|----------------|
| InsightForge (MaazLab) | 多智能体文章撰写工具 | 本项目聚焦**市场验证**，而非通用内容生成 |
| InsightForge AI (SypherKx) | 医疗与教育领域的 RAG 平台 | 本项目面向**创业与产品**场景，数据源为公开网络 |
| n8n | 通用工作流自动化平台 | 本项目**无需注册**，聚焦市场调研单一场景 |


## 二、项目背景

### 2.1 市场痛点

| 痛点 | 描述 |
|------|------|
| **想法美好，市场未知** | 创业者常有好的想法，但不确定是否真实存在市场需求 |
| **调研耗时数周** | 手动搜索、整理、分析信息，效率极低 |
| **工具碎片化** | 需要同时使用搜索引擎、论坛、分析工具等多个平台 |
| **数据难以沉淀** | 调研结果散落各处，无法形成可复用的知识库 |
| **注册流程繁琐** | 现有自动化工具大多要求注册云账号，增加使用门槛 |

### 2.2 解决思路

InsightForge 个人版通过**“智能体驱动”**的方式，将原本需要人工完成的市场调研流程自动化：

1. **输入想法** → 用户只需描述一个产品概念
2. **自动采集** → 系统从搜索引擎、论坛、社交媒体抓取相关数据
3. **智能分析** → AI 智能体整合数据，生成结构化市场报告
4. **一键验证** → 生成可分享的落地页，用于“假门测试”

### 5.3 外部依赖

个人版仅需两个外部 API Key：

| 依赖项 | 用途 | 是否可替换 |
|--------|------|------------|
| **大语言模型 API Key**（DeepSeek / OpenAI） | 驱动智能体进行分析和报告生成 | ✅ 可替换为本地 Ollama |

### 5.4 关键技术组件说明

#### 5.4.1 Hermes Agent —— 自进化的首席执行官智能体

Hermes Agent 是由 Nous Research 构建的自进化 AI 智能体，是本项目的“首席执行官 Agent”核心。其关键特性包括：

- **内置学习闭环**：从经验中创建技能，在使用中改进技能，主动持久化知识
- **跨会话记忆**：搜索过往对话，在跨会话中逐步构建对用户的深度理解
- **轻量运行**：可在 $5/月的 VPS 上运行
- **广泛采用**：上线不足三个月即突破 14 万 GitHub 星标

#### 5.4.2 Mastra —— TypeScript 智能体框架

Mastra 是一个用于构建 AI 智能体、工具和工作流的 TypeScript 框架。它支持从原型到生产环境的全流程开发，可集成 React、Next.js、Node 等前端和后端框架。

#### 5.4.3 DeepSeek Harness —— 原型生成引擎

DeepSeek Harness（dsh）是 DeepSeek AI 开发的开源智能体框架。其核心架构为 **“一切皆插件”** —— 模型接入、工具执行、会话记录、界面全部走插件机制。它提供标准、最小、代码和创作者 4 种运行模式，本项目主要利用其**代码模式**生成验证落地页。

#### 5.4.4 Crawlee + Playwright —— 数据采集引擎

Crawlee 提供端到端的爬虫和抓取能力。其 `PlaywrightCrawler` 类可控制 Chromium、Chrome、Firefox、Webkit 等多种浏览器，支持 JavaScript 渲染页面的数据采集，是处理现代 Web 应用的首选方案。

#### 5.4.5 Workflow Automation MVP —— 轻量级工作流引擎

这是一个简化版的工作流自动化平台，灵感来自 n8n。其核心优势是**无需认证**、开箱即用，提供可视化工作流构建器、REST API 和实时日志，完美契合本项目的 MVP 定位。

#### 5.4.6 Casdoor —— 身份管理（预留扩展）

Casdoor 是开源、AI-first 的身份与访问管理平台，支持 OAuth 2.0、OIDC、SAML 等标准协议。个人版暂不启用，预留用于未来团队版的用户管理扩展。


## 七、使用说明

### 7.1 第一次使用

1. 访问 `http://localhost:3000`
2. 在输入框中描述你的产品想法（一句话即可）
3. 点击 **“验证想法”**
4. 等待 2-5 分钟，系统自动生成市场报告
5. 浏览报告，查看数据来源和分析结论
6. （可选）点击 **“生成验证页”** 获得可分享的落地页链接

### 7.2 报告内容说明

| 报告章节 | 内容说明 |
|----------|----------|
| **执行摘要** | 核心结论一句话总结 |
| **市场热度分析** | 基于搜索引擎结果数量、论坛讨论量等量化指标 |
| **竞品识别** | 自动识别 3-5 个主要竞品及其特点 |
| **用户痛点提取** | 从论坛评论中提取的高频抱怨和需求 |
| **市场规模估算** | 基于公开数据的粗略估算 |
| **风险与机会** | 自动识别的市场进入风险和潜在机会点 |
| **数据来源** | 所有引用数据的来源链接 |

### 7.3 数据源配置

个人版默认集成了以下数据源：

- **搜索引擎**：Google / Bing（通过 OpenSerp）
- **技术社区**：Hacker News、Reddit（指定子版块）
- **产品社区**：Product Hunt（公开数据）
- **后续可扩展**：App Store 评论、知乎、Twitter 等

## 九、常见问题（FAQ）

### Q1：我必须联网才能使用吗？
**A**：是的，报告生成需要调用大模型 API 和搜索引擎 API。但你可以选择使用本地模型（Ollama）来减少对公网的依赖。

### Q2：我的数据会被上传到云端吗？
**A**：**不会**。所有数据存储在本地 SQLite 数据库中，只有 API 调用会向外发送查询请求。

### Q3：可以替换成其他大模型吗？
**A**：可以。支持 OpenAI 兼容接口的任何模型，包括 DeepSeek、Claude、Groq 等。也支持通过 Ollama 使用本地模型。

### Q4：爬虫会被目标网站封禁吗？
**A**：个人版默认使用 OpenSerp 作为搜索入口，并配置了合理的请求频率。如需大规模采集，建议配置代理池。

### Q5：报告生成大概需要多长时间？
**A**：通常在 2-5 分钟，取决于网络速度和 API 响应时间。本地需求库命中缓存时可缩短至 30 秒内。

### Q6：Hermes Agent 在项目中具体做什么？
**A**：Hermes Agent 作为“首席执行官智能体”，负责协调整个调研流程——拆解用户任务、调度子智能体、管理跨会话的学习和记忆，使系统能随着使用不断进化。
